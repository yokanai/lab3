# Отчет по лабораторной работе №3

## 1. Данные и подготовка
- **Student Performance**: Категориальный признак `Extracurricular Activities` переведен в бинарный (0/1). Все признаки стандартизированы с помощью `StandardScaler` (это критически важно для стабильной работы градиентного спуска). Данные разделены на train/test в пропорции 80/20 (random_state=42).
- **German Credit**: Данные прочитаны с разделителем `;`. Целевая переменная `Creditability` (классы 1 и 2) переведена в 0 и 1. Категориальные признаки закодированы через One-Hot Encoding (`pd.get_dummies`). Признаки стандартизированы. Разделение на train/test 80/20 со стратификацией (`stratify`), чтобы в тестовой выборке гарантированно были оба класса.

## 2. Гипотезы и эксперименты
- Для линейной регрессии выбраны параметры `learning_rate=0.05` и `epochs=800`. Ошибка MSE монотонно убывала, что говорит о корректной настройке скорости обучения.
- Для логистической регрессии выбраны `learning_rate=0.1` и `epochs=1000`. Сравнение проводилось с `DecisionTreeClassifier` и `KNeighborsClassifier` из `scikit-learn` на одинаковых отмасштабированных данных.

## 3. Метрики
- **Linear Regression MSE на тесте**: 4.1697

Результаты сравнения классификаторов (метрика ROC-AUC):
- **Собственная Логистическая Регрессия**: ROC-AUC = **0.8081**
- **K-Neighbors Classifier (KNN)**: ROC-AUC = **0.7412**
- **Decision Tree Classifier**: ROC-AUC = **0.6226**

## 4. Выводы
Собственная реализация логистической регрессии с пакетным градиентным спуском показала лучший результат (AUC 0.8081), превзойдя дерево решений и KNN. Это объясняется тем, что данные после One-Hot Encoding и стандартизации хорошо разделяются линейной гиперплоскостью. Дерево решений показало слабый результат (0.6226), так как склонно к переобучению на обучающей выборке и плохо улавливает линейные зависимости в многомерном пространстве признаков после One-Hot кодирования. KNN показал достойный результат, так как признаки были отмасштабированы.
